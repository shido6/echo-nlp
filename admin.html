What this console covers

Honest edges, up front.

Credits

Admin-managed here, on an append-only ledger. Card payments still go through Stripe and PayPal — this is the internal balance, not a payment rail.

Tenants

God mode sees everything. A tenant admin sees and manages their own tenant’s users and balances only.

Network

The whitelist, IP blocks and rate-limit resets are platform-level — god mode only, always audited.

Access

Admin needs an admin account and a whitelisted network. Both, always. Localhost is always allowed — the box itself.
